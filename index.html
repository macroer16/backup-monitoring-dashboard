    How it works

    1. Every night at 02:23 UTC a GitHub Actions job lists my public repositories and mirrors each one, with every branch and tag.
    2. Each mirror is packed into a single git bundle file, checked with git bundle verify, and given a SHA-256 checksum.
    3. Restore test: the job restores every bundle into a fresh folder and checks that the latest commit matches. A backup that can't be restored counts as failed.
    4. Bundles are kept for 30 days as job artifacts. The results are added to history.json on the backup-data branch, which is what this page reads.
    5. A failure opens a GitHub issue, which emails me, and the issue closes itself when the next backup works.
